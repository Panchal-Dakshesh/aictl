# aictl

**A control plane for your AI coding sessions.**

You talk to Claude Code in one terminal, Codex in another, Cursor in the editor and Antigravity on the side. Each one keeps its own history in its own format, in its own corner of your disk. `aictl` puts all of them in one list, lets you search every message, and moves context between them.

```
╭─ sources ──────────╮╭─ sessions 6 ─────────────────────────────────╮╭─ preview ──────────────────────────────╮
│   all            6 ││ 3d   codex       add a dead letter topic…    ││ add a dead letter topic to the kafka…  │
│ ● claude         1 ││ 4d   claude      Fix flaky checkout test     ││ codex · ~/Work/pipeline · ⎇ feat/cdc   │
│ ● codex          2 ││ 5d   gemini      make the hero section…      ││ 2 msgs · Oct 2 10:00 · gpt-5-codex     │
│ ● gemini         1 ││ 12d  cursor      Landing page copy           ││ ↵ codex resume 22222222…               │
│ ● antigravity    1 ││ 2w   antigravity Voice assistant backend     ││                                        │
│ ● cursor         1 ││ 1y   codex       explain this regex          ││ › add a dead letter topic to the kafka │
╰────────────────────╯╰──────────────────────────────────────────────╯╰────────────────────────────────────────╯
 NORMAL  aictl  codex · ~/Work/pipeline · 2 msgs                                                  ? help  1/6
```

## What it does

- **One list.** Claude Code, Codex CLI, Gemini CLI, Google Antigravity and Cursor sessions, newest first, with project, branch and model.
- **Search everything.** `/` filters as you type (`tool:codex p:pipeline`), `:grep` searches inside every transcript.
- **Resume.** `↵` reopens a session in its own tool, in the folder it was started from. When you quit it, you're back in aictl. Inside tmux, every session opens in its own window and aictl stays up as the dashboard, so you can run several at once.
- **Hand off.** `s` starts a *different* tool with the conversation as its opening context. Started something in Antigravity, want to finish it in Claude Code? One key.
- **Attach.** `a` writes a brief and copies one line you can paste into a session that's already running.
- **Memory.** `m` shows `CLAUDE.md`, `AGENTS.md`, `GEMINI.md` and Cursor rules for the project side by side: edit, diff, and copy one over another (with a backup).
- **Safe.** Read-only on every tool's data. Nothing leaves your machine. Briefs mask things that look like API keys.

## Built from scratch

No TUI framework, no third-party Go modules. The terminal layer (raw mode, input decoding, a double-buffered screen that only redraws changed cells) is in `internal/term`. Antigravity stores conversations as protobuf with no published schema, so `internal/sources/protowire.go` walks the wire format directly.

The index works like change data capture on your own history: each session file is fingerprinted by size and mtime, and only files that changed since the last run are parsed again.

## Install

```sh
go install github.com/Panchal-Dakshesh/aictl/cmd/aictl@latest
```

or grab a binary from Releases. Antigravity and Cursor support uses the `sqlite3` CLI that ships with macOS.

## Use

```sh
aictl                          # the TUI
aictl list --tool claude -n 10
aictl show 1a2b3c              # transcript as Markdown (any unique id prefix)
aictl resume 1a2b3c
aictl send 1a2b3c --to codex   # hand off (add --full for the whole transcript)
aictl attach 1a2b3c
aictl memory .
aictl doctor                   # where aictl looked, what it found
```

| key | does |
| --- | --- |
| `j` `k` `h` `l` | move, switch panes |
| `/` | filter (`tool:` `p:`) |
| `:grep text` | search inside transcripts |
| `o` / `space` | read the transcript |
| `↵` | resume |
| `s` | hand off to another tool |
| `a` / `A` | attach (compact / full) |
| `y` | copy the resume command |
| `m` | memory files: `e` edit, `d` diff, `S` sync |
| `?` | help |

## Where each tool keeps things

| tool | sessions | resume |
| --- | --- | --- |
| Claude Code | `~/.claude/projects/<dir>/<id>.jsonl` | `claude --resume <id>` |
| Codex CLI | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` | `codex resume <id>` |
| Gemini CLI | `~/.gemini/tmp/<hash>/chats/*.json` | `gemini --resume <id>` |
| Antigravity | `~/.gemini/antigravity/conversations/<id>.db` | hand off only |
| Cursor | `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` | hand off only |

None of these formats are documented, and they change. Each adapter is one file in `internal/sources` with fixtures in `testdata/home` (all made up, generated by `scripts/mkfixtures.py`; dot-dirs are stored as `dot-claude` etc. and renamed in tests). If a tool update breaks one, `aictl doctor` says so instead of crashing.
